# 0010. 경쟁 대신 나눔 — 순위 없음 + 이웃 교회 온기

- 상태: 채택
- 날짜: 2026-11-12

## 배경
"우리 교회"끼리 경쟁 구도가 되면 교회 간 비교·위화감이 생길 수 있다.

## 결정
- 순위표·"몇 위" 없음. 검색은 거리순, 다른 교회의 누적 시간과 성도 수는 서버가 돌려주지 않는다 (단계만 공개)
- 기도 시간은 내 교회에 100% 그대로 쌓이고, 추가로 일정 비율이 주변 교회 몇 곳에 "온기"로 더해진다. 단계가 낮은 교회에 더 많이. 교회가 없는 사람의 기도도 온기를 보낸다
- 비율·반경·교회 수는 `app_config.church_sharing`으로 운영하며 확정 (임시 10% · 10km · 5곳)
- 지구본에서 이웃 교회로 가는 빛은 내 교회 항로보다 가늘고 흐리고 느리게
- 다른 교회를 위한 중보기도 버튼은 넣지 않음

## 이유
비교할 수단을 없애고 내 기도가 이웃에도 닿게 해서, 기능이 교회 간 경쟁이 아니라 함께 세우는 경험이 되게 한다.

## 영향 · 후속
- 온기 계산은 기도 시간이 저장될 때 DB 트리거가 한다 (`church_warmth`, 클라이언트 접근 불가)
- 기도 시간 자체가 클라이언트 저장이라 온기도 같은 신뢰 수준. 서버측 시간 검증은 백로그
