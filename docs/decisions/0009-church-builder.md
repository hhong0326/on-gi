# 0009. 우리 교회 세우기

- 상태: 채택
- 날짜: 2026-11-12

## 배경
혼자 기도하고 끝나는 경험이라 다시 올 이유와 함께할 사람을 부를 이유가 약했다. 기획서(비공개 링크, 소유자만 열람): https://claude.ai/artifact/JjsgtsJjg55NYFSGwNQg9G

## 결정
- 교회를 검색하거나 지도 핀으로 세우고 내 교회로 등록한다. 외부 장소 API 없이 앱 안에 세워진 교회만 검색
- 성장은 그 교회 성도 전체의 기도 시간 공동 합산
- 8단계: 초막 → 회막 → 가정교회 → 바실리카 → 로마네스크 → 고딕 대성당 → 사그라다 파밀리아 → 빛의 교회. 기준 시간은 `app_config.church_levels`(초안 1/5/15/40/100/250/600시간)
- 교회 위치는 정확히 저장 (공공장소)
- "우리 교회"는 설정 화면 안에. 교회 변경 제한 없음
- 일러스트는 `public/churches/lv1~8.svg` 초안. 디자이너가 디자인 규약에 맞게 다듬어 파일만 교체

## 이유
공동체가 함께 짓는 경험을 만들고, 성경과 실제 교회 건축사를 따라 의미 있는 단계를 준다. 7단계는 로마네스크와 실루엣이 겹치던 한국 붉은 벽돌 예배당 대신 사그라다 파밀리아(글로벌 앱이라 무방, "함께 지어져 가는" 상징).

## 영향 · 후속
- 마이그레이션: `supabase/migrations/20261112033958_church_builder.sql`
- 기도 기록이 하루 1행이라, 하루 중 교회를 바꾸면 그날 기도 시간 전체가 새 교회로 옮겨간다 (허용)
- 2차: 지구본 교회 아이콘·항로선, 레벨업 연출 / 3차: 신고·숨김
