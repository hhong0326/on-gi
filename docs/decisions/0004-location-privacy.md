# 0004. 개인 기도 위치는 약 10km 격자 + 결정적 흩뿌림

- 상태: 채택
- 날짜: 2026-07-08

## 배경
기도 위치를 지도에 공개하므로 개인의 정확한 위치가 드러나면 안 된다. 격자로만 반올림하니 불빛이 바둑판처럼 겹쳐 보였다.

## 결정
저장은 위경도를 0.1도(약 11km) 단위로 반올림한다. 화면 표시는 기도 id로 계산한 ±0.04도 흩뿌림(jitter)을 더한다. DB는 바꾸지 않는다.

## 이유
정확한 위치를 저장하지 않으면서, 같은 기도는 항상 같은 자리에 보인다.

## 영향 · 후속
- 반경 계산(예: 이웃 교회 나눔)은 이 흐린 좌표 기준이라 10km보다 작은 반경은 의미가 없다
- 교회 위치는 공공장소라 예외로 정확히 저장한다 (0009)
