# 0008. 온보딩 닉네임 빈칸 타이핑 데모

- 상태: 채택
- 날짜: 2026-11-11

## 배경
"____는 세상의 빛이라" 빈 밑줄만 있어서 사용자들이 닉네임을 넣어야 하는 줄 몰랐다.

## 결정
안내 문구 대신 빈칸에 예시 이름(언어별)이 써졌다 지워지는 데모를 보여준다. 포커스하면 영구 중단. 받침에 따라 은/는 자동 선택. 모션 축소 설정이면 정적 표시.

## 이유
말씀 문장 콘셉트를 해치지 않고 입력란임을 보여준다.

## 영향 · 후속
- autoFocus 제거 (데모가 바로 꺼지므로). iOS에서는 원래도 키보드가 안 떴다
