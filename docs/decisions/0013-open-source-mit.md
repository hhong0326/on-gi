# 0013. 오픈소스 공개 (MIT)

- 상태: 채택
- 날짜: 2026-11-12

## 배경
저장소가 이미 공개 상태이고, 기독교 공동체 앱으로서 다른 사람들도 가져다 쓰고 기여할 수 있으면 좋다.

## 결정
MIT 라이선스로 공개한다. 결정 로그와 Memory Bank도 저장소에 두되 프로젝트 내용만 올린다 (개인 정보·키·운영 수치 제외).

## 이유
가장 널리 쓰여 기여자 유입에 유리하다.
