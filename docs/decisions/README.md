# 결정 로그 (ADR)

ON-GI의 주요 결정을 한 건씩 기록한다. **왜 이렇게 만들었는지**를 나중에 사람과 AI 에이전트가 다시 묻지 않도록 하는 것이 목적이다.
현재 상태 요약은 [docs/memory/](../memory/)에 있고, 그 내용의 근거가 이 로그다.

## 규칙

- 결정 1건 = 파일 1개, 번호는 순서대로 (`NNNN-짧은-이름.md`)
- **지우거나 내용을 고치지 않는다.** 결정을 뒤집을 때는 새 ADR을 쓰고, 이전 ADR의 상태만 `대체됨 → NNNN`으로 바꾼다
- 작게 쓴다: 배경 · 결정 · 이유 · 영향/후속
- 결정을 기록하면 [docs/memory/project-state.md](../memory/project-state.md)도 함께 갱신한다

## 언제 쓰나

- 기능의 방향을 정했을 때 (무엇을 넣고 무엇을 뺄지)
- 기술 선택, 데이터 구조, 보안·프라이버시 정책
- 되돌리기 어렵거나, 나중에 "왜 이렇게 했지?"라는 질문이 나올 만한 것

## 형식

```markdown
# NNNN. 제목

- 상태: 채택 | 대체됨 → NNNN | 보류
- 날짜: YYYY-MM-DD

## 배경
## 결정
## 이유
## 영향 · 후속
```
