# 0012. Supabase CLI는 2.122.0으로 고정

- 상태: 채택
- 날짜: 2026-11-12

## 배경
`npx supabase`가 3.x를 받아오는데, 3.x는 `supabase/config.toml`의 `[inbucket]` 섹션을 거부해 마이그레이션·타입 생성이 실패한다 (타입 파일이 에러 내용으로 덮어써지기도 함).

## 결정
CLI 명령은 `npx -y supabase@2.122.0 ...`으로 실행한다.

## 이유
설정 파일을 바꾸지 않고 지금 동작하는 버전을 유지한다.

## 영향 · 후속
- 3.x로 올리려면 config.toml의 `[inbucket]`을 `[local_smtp]`로 옮기는 작업을 별도로 한다
- 타입 생성은 임시 파일로 받은 뒤 확인하고 교체한다
