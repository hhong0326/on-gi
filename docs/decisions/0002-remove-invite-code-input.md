# 0002. 초대코드 입력 UI 제거

- 상태: 채택
- 날짜: 2026-06-22

## 배경
초기에는 초대코드 입력 화면(S00)으로 진입을 제한했다. 모바일에서 버튼 터치 불가, disabled·터치 이벤트 문제가 여러 번 고쳐도 반복됐다.

## 결정
초대코드 입력 UI를 완전히 제거하고 바로 닉네임 온보딩으로 진입한다. 접근 제한이 필요하면 서버 쪽에서 처리한다.

## 이유
진입 마찰을 없애는 것이 익명 기도 앱의 핵심 경험이고, 반복된 모바일 버그의 원인을 구조적으로 없앤다.

## 영향 · 후속
- 초대코드 입력 UI를 다시 추가하지 않는다
- 초대 링크(`/invite/[code]`, `?code=`)는 OG 메타 용도로만 남아 있다
