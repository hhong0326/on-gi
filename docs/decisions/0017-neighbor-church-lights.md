# 0017. 기도 중 이웃 교회로 가는 희미한 빛

- 상태: 채택
- 날짜: 2026-11-25

## 배경
"교회에 빛 보내기" 3단계. 기도 시간의 일부는 이미 이웃 교회에 온기로 나뉜다(0009·0010). 이 나눔은 기도를 마친 뒤 완료 창의 숫자로만 보였다.

## 결정
- 기도 중에 내 불빛에서 이웃 교회들로 가는 희미한 빛을 그린다. 내 교회 빛(0016)보다 가늘고 흐리고 느리다(3.6초 주기). 내 교회가 없어도 이웃 빛은 보인다
- 이웃 목록은 서버 RPC `get_prayer_neighbors(p_prayer_id)`가 정한다. 규칙은 온기 트리거(`recompute_prayer_warmth`)와 같다: 저장된 기도 위치(0.1도 격자) 반경 `radiusKm` 안, 그 기도의 교회 제외, 가까운 순 최대 `maxChurches`곳. 그래서 빛이 가는 곳 = 온기가 가는 곳
- RPC는 내 기도만 받고(남의 기도 id면 빈 결과), 교회 id·위치만 돌려준다. 나눔 시간·단계는 내보내지 않는다 (0010). 위치는 이미 지구본에 공개된 값
- 출발점은 화면의 내 불빛(격자 + 흩뿌림)이라 실제 위치가 드러나지 않는다 (0004)
- 실패하면 빛만 생략한다. 기도 흐름은 막지 않는다

## 이유
온기 나눔을 숫자가 아니라 기도하는 동안의 빛으로 느끼게 한다. 화면에서 따로 계산하면 실제 온기와 어긋날 수 있어 서버가 같은 규칙으로 고른다.

## 영향 · 후속
- DB: `supabase/migrations/20261125000000_prayer_neighbors.sql` (함수 1개, 테이블 변경 없음)
- 코드: `church-route.ts`를 목적지 여러 곳 + 강도 두 가지('church' | 'neighbors')로 일반화, `usePrayerNeighbors`
- 알려진 차이: 아주 짧은 기도는 온기 배분이 0초로 내려가 일부 교회가 실제 온기를 못 받을 수 있다 (빛은 보임)
- 규칙을 바꿀 때는 트리거와 이 RPC를 함께 고친다
