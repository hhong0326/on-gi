# 0011. 교회 없는 사용자에게 기도 시작 시 하루 1회 안내

- 상태: 채택
- 날짜: 2026-11-12

## 배경
교회 기능을 모르는 사용자에게 알릴 지점이 필요했다.

## 결정
기도는 막지 않고 바로 시작되며, 기도 마치기 버튼 위에 안내 카드를 6초 띄운다(하루 1회, 기기 로컬 기록). 기도 완료 모달에도 "이웃 교회 N곳에 온기" + 등록 유도 문구.

## 이유
안내 때문에 기도 시작이 늦어지지 않고, iOS 음원 재생도 버튼 제스처 안에서 유지된다.
