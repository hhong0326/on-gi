# 0007. 지구본도 웜 톤으로 덮어쓰기

- 상태: 채택
- 날짜: 2026-11-04

## 배경
Mapbox dark-v11 스타일은 레이어가 전부 무채색 회색이라 톤온톤 화면에서 지구본만 차갑게 보였다.

## 결정
Mapbox Studio 커스텀 스타일 대신, 로드 시 레이어 paint 값을 웜 톤으로 덮어쓴다. 우주 배경은 앱 베이스와 같은 `ember` fog.

## 이유
코드로 관리·되돌리기가 쉽고 비용이 들지 않는다.

## 영향 · 후속
- [src/lib/map-tone.ts](../../src/lib/map-tone.ts). Mapbox가 레이어 id를 바꾸면 그 레이어만 회색으로 남고 깨지지는 않는다
- 육지는 골드 기도 불빛과 대비가 남도록 아주 어둡게 유지
